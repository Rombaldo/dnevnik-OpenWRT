# Мой дневник — домашка, оценки и расписание из Дневник.ру на домашнем роутере

Простая страница для школьника: что задали, какие оценки, какие уроки. Живёт на роутере с OpenWrt,
работает круглосуточно по домашней Wi-Fi, ничего включать не нужно. По желанию дневник открывается и **из интернета** по постоянному адресу, с любого
телефона без приложений (под паролем семьи). Компьютер нужен только один раз для установки. **Установка от нуля до работающего дневника: раздел «Быстрый старт» ниже.**

> **Это неофициальная программа.** Она не связана с «Дневник.ру» и школой, ничего не взламывает и не обходит платные функции:
> только читает то, что сайт сам показывает ученику, по его логину и паролю. Условия сайта могут запрещать автоматический доступ,
> а устройство сайта может измениться, и тогда программа перестанет работать. Используйте на свой риск.
> Никаких данных никуда не отправляется: всё хранится только на вашем роутере или компьютере. Доступ из интернета (по желанию) идёт через Tailscale Funnel:
> данные остаются на роутере, а шифрование (HTTPS) завершается на самом роутере.

## Что показывает
- В шапке: имя ученика и школа, как на сайте (например, «Аня (МБОУ "Школа № 1")»).
- **Домашка:** лента по дням, задания с отметкой «сделано», вложения-файлы ссылкой.
- **Оценки:** «Сейчас» (последние оценки и все оценки по предметам; **нажмите на оценку** (и здесь, и в «Домашке», и в расписании): откроется карточка, как на сайте — за что поставлена, учитель, тема урока, оценка и средний балл по предмету со стрелкой ↑/↓, подняла ли эта оценка средний балл) и «По годам и итоги»: все учебные годы ученика,
  оценки по триместрам со средним баллом и итоговые оценки (за каждый триместр и за год), как в разделе «Успеваемость» на сайте.
- **Посещаемость:** сколько уроков и сколько дней пропущено (по болезни и по другим причинам), опоздания, процент посещаемости, по каждому триместру
  и за год; можно раскрыть список дней с пропусками. Короткая сводка за идущий триместр лежит на вкладке «Оценки» → «Сейчас».
- **Посещаемость (отдельная кнопка в «Оценках»):** календарь по дням за выбранный триместр и год. Цветом отмечены дни болезни,
  пропуски и опоздания; нажмите на день, чтобы увидеть причину и какие именно уроки (и по каким предметам) пропущены. Ниже список
  дней с пропусками. В идущем году зелёным отмечены дни, когда ученик был на уроках; в прошлых периодах тоже зелёные все будни без пропусков.
- **Настройки (кнопка ⚙ в шапке):** тема (авто, светлая, тёмная), размер текста и кнопок (одинаковый на всех экранах),
  листание дней свайпом (можно выключить), «Домашка» лентой или по одному дню (со стрелками и свайпом, как расписание),
  учителя рядом с уроками, какая вкладка открывается при запуске, сброс настроек. Настройки хранятся на самом телефоне или планшете.
  Там же кнопка «Выйти из аккаунта».
- **Расписание:** по дням, листается свайпом. С учителями: рядом с уроком фамилия и инициалы, а кнопка «Учителя» показывает
  всех учителей по предметам с полными именами и должностями.

## Быстрый старт: от нуля до работающего дневника

Это путь для человека, который делает всё в первый раз (три способа: с компьютера, по SSH или с помощью ИИ-агента). Нужно 15–20 минут. Если что-то не получилось, в конце есть проверка и таблица «что делать».

**Что понадобится**

| Что | Зачем |
|---|---|
| Роутер с **OpenWrt** (проверено на Cudy WBR3000UAX, OpenWrt 25.12) и его пароль | дневник живёт на роутере и работает круглосуточно |
| Компьютер (Windows, Mac или Linux) в той же домашней сети | с него запускается установка |
| Логин и пароль ученика в Дневник.ру (или вход через Госуслуги) | чтобы дневник мог читать домашку и оценки |
| Около 6 МБ свободного места на роутере (и около 15 МБ, если нужен доступ из интернета) | это проверяется само |
| *Для доступа из интернета:* бесплатный аккаунт [Tailscale](https://tailscale.com) | у каждой семьи свой аккаунт и свой адрес |

**Совместимость**

| | Статус |
|---|---|
| **OpenWrt 25.12** (пакетный менеджер `apk`) | **проверено** на Cudy WBR3000UAX |
| OpenWrt 24.10, 23.05, 22.03, 21.02 (`opkg`) | должно работать (установщик умеет `opkg`, нужные пакеты Python и LuCI там есть), **но не проверялось**; если что-то не так, пришлите `doctor.py --report` |
| OpenWrt старше 21.02, не-OpenWrt прошивки | не поддерживается (другие LuCI и Python) |
| Роутер без места (меньше ~6 МБ свободно) | дневник не встанет; для доступа из интернета нужно ещё ~15 МБ и ≥ 128 МБ оперативной памяти |
| Компьютер для установки: **Windows 10/11, macOS, Linux** | поддерживается (в Windows 10/11 включите «Клиент OpenSSH»: Параметры → Приложения → Дополнительные компоненты) |
| Компьютер: **Windows 7 / 8** | возможно с оговорками, см. ниже |

**Windows 7 и 8.** Microsoft и разработчики программ их не поддерживают, и я это на них **не проверял**. Установка с компьютера возможна, но: (1) нужен **Python 3.8** (последний, работающий на Windows 7;
python.org, при установке отметьте «Add Python to PATH»); (2) в Windows 7 **нет программы ssh**: поставьте **Git for Windows** (git-scm.com, ssh идёт в комплекте) и запускайте `python tools/setup_computer.py` из «Git Bash»;
(3) вход через Госуслуги (`tools/login_computer.py`) на Windows 7 **не работает** (браузер Chromium, который он использует, её не поддерживает): сделайте этот шаг на любом другом компьютере или войдите на странице по логину и паролю.
Самый простой путь: поставить с другого компьютера (Windows 10/11, Mac, Linux) или способом Б из «PuTTY» (одна команда). Программа установки сама проверяет это и подсказывает.

**Способ А: с компьютера, без терминала (рекомендуется)**

1. Скачайте программу: на странице репозитория на GitHub нажмите «Code» → «Download ZIP» и распакуйте архив.
2. Запустите установку:
   - **Windows:** дважды щёлкните по файлу `setup-windows.bat` (нужен установленный Python: python.org, при установке отметьте «Add to PATH»);
   - **Mac:** дважды щёлкните по файлу `Установить-на-роутер.command` (если Mac не даёт открыть: правый щелчок → «Открыть»);
   - **Linux:** `python3 tools/setup_computer.py`.
3. Отвечайте на вопросы простыми словами: адрес роутера (программа сама предложит), нужна ли страница в веб-интерфейсе роутера, нужен ли доступ из интернета, пароль для семьи.
4. Один раз введите пароль роутера (тот, что для его веб-интерфейса; при вводе символы не видны).
5. Если выбрали доступ из интернета, программа сама откроет браузер и скажет, что нажать: **«Connect device»**, потом **«Enable Funnel»**. После второго нажатия запустите программу ещё раз: сделанное она пропустит.
6. В конце программа помогает войти в Дневник.ру и печатает адреса.

**Способ Б: по SSH** (для тех, кто привык к терминалу). Подключитесь `ssh root@адрес-роутера` и выполните:

```
wget -qO- https://raw.githubusercontent.com/Rombaldo/dnevnik-OpenWRT/main/router/install.sh | sh -s -- --luci
```

Потом откройте страницу и войдите в Дневник.ру (раздел «Как поставить на роутер» ниже), задайте пароль для семьи (⚙ на странице или LuCI), и, если нужен доступ из интернета:

```
sh /root/dnevnik/router/remote.sh
```

Команда сама скажет, что нажать в браузере, и её можно запускать повторно.

**Способ В: с помощью ИИ-агента** (Claude Code, ChatGPT Codex, Cursor, Aider, DeepSeek-харнесс или любая модель). В репозитории лежит файл **`AGENTS.md`**: подробная инструкция именно для ИИ-агента, как провести вас
весь путь от пустого роутера до работающего дневника (вопросы, проверки после каждого шага, что делать при ошибках, правила безопасности). Агент задаёт вам вопросы и просит разрешения там, где это нужно.
Пароли он просить не будет: их вы вводите сами. Как пользоваться:

1. Скачайте программу (как в способе А) и откройте папку в своём ИИ-инструменте. Claude Code сам подхватит `CLAUDE.md`, Codex и другие читают `AGENTS.md`.
2. Скажите: *«Прочитай AGENTS.md и установи «Мой дневник» на мой роутер. Спрашивай меня, когда нужен выбор или моё действие. Пароли в чат не проси.»*
3. Если инструмент не умеет читать файлы репозитория, дайте ему ссылку: `https://raw.githubusercontent.com/Rombaldo/dnevnik-OpenWRT/main/AGENTS.md`. Без доступа к терминалу агент работает как проводник: говорит, какую команду выполнить, и разбирает то, что вы вставите.

**Дальше**

- **Войти в Дневник.ру.** Если ученик входит на сайт по логину и паролю, введите их на странице дневника. Если только через Госуслуги, используйте `tools/login_computer.py` (раздел «Войти заново через компьютер» ниже).
- **Пароль семьи.** Один общий пароль; задаётся на странице (⚙) или в LuCI. Для доступа из интернета обязателен: без него программа не выставит дневник наружу.
- **Доступ из интернета (по желанию).** Постоянный адрес вида `https://dnevnik.<ваша-сеть>.ts.net`: открывается с любого телефона без приложений, сохраняется на экран «Домой» как приложение. Подробности и «зачем нужен прокси» ниже в разделе «Доступ из интернета (Tailscale Funnel)».
- **Уведомления на телефон (по желанию).** `sh /root/dnevnik/router/push.sh`, потом на телефоне ⚙ → «Уведомления». Подробности ниже в разделе «Уведомления».
- **Проверка, что всё работает.** `python3 /root/dnevnik/router/doctor.py` на роутере или кнопка **«Проверить всё»** в LuCI («Службы → Дневник»). Она покажет зелёное и красное и что делать с каждой проблемой. Установщик запускает её сам в конце.
- **Попросить помощи.** `python3 /root/dnevnik/router/doctor.py --report`: текст без паролей, логинов, имён и адресов; его можно спокойно переслать тому, кто помогает.

**Если что-то пошло не так**

| Что видите | Что делать |
|---|---|
| Программа установки не может подключиться к роутеру | проверьте адрес (обычно 192.168.1.1 или 192.168.0.1) и пароль роутера; компьютер должен быть в домашней сети |
| «Не хватает места» | освободите место на роутере (удалите ненужные пакеты) или подключите флешку; дома дневник работает и без выхода в интернет |
| Страница открывается дома, а вне дома нет | запустите «Проверить всё»; чаще всего Funnel не включён: `sh /root/dnevnik/router/remote.sh` |
| «Tailscale не подключился» | в окне Tailscale нужно нажать именно **«Connect device»**; если нажали, а не заработало, смотрите раздел «Доступ из интернета» (прокси) |
| Страница вне дома иногда не открывается с первого раза | известная особенность Funnel: обновите страницу ещё раз, обычно хватает 1–3 попыток |
| Дневник просит войти в Дневник.ру заново | введите логин и пароль на странице или повторите вход через Госуслуги |
| Забыли пароль семьи | задайте новый в LuCI («Службы → Дневник → Пароль семьи»), старый знать не нужно |

## Подробно: установка по SSH (и как поставить заново после форматирования)

**Нужно:** роутер с OpenWrt (проверено на Cudy WBR3000UAX, OpenWrt 25.12), доступ к интернету на роутере,
около 6 МБ свободной памяти. Всё остальное скрипт доустановит сам.

**1. Подключитесь к роутеру по SSH** (терминал на Mac или Windows: `ssh root@192.168.10.1`) и вставьте **одну из двух команд**.

Обычная, без веб-интерфейса роутера (по умолчанию, ничего лишнего):

```
wget -qO- https://raw.githubusercontent.com/Rombaldo/dnevnik-OpenWRT/main/router/install.sh | sh
```

Или с пунктом **«Службы → Дневник»** в веб-интерфейсе роутера (LuCI): состояние, кнопки «Обновить сейчас» и «Проверить новую версию»,
расписание обновлений, имя в шапке, **пароль для семьи**, **устройства и входы**, доступ из интернета и проверка, журнал, выход из аккаунта. Нужен LuCI на роутере (пакет `luci-base`); если его нет, установщик
скажет об этом, а дневник всё равно поставится. Занимает около 20 КБ и ничего не запускает в фоне:

```
wget -qO- https://raw.githubusercontent.com/Rombaldo/dnevnik-OpenWRT/main/router/install.sh | sh -s -- --luci
```

Скрипт сам поставит нужные пакеты, скачает программу, включит службу и расписание обновлений.
В конце напишет адрес страницы. Передумали? Повторите установку с ключом `--luci` или `--no-luci` (убрать страницу LuCI).
Если страница LuCI уже стоит, обычное обновление без ключей обновляет и её.

**2. Откройте страницу на телефоне или планшете** (они должны быть в домашней Wi-Fi): **`http://dnevnik.lan`**.
Это имя, а не цифры, поэтому оно не зависит от адреса роутера (192.168.1.1, 192.168.73.1 — каким бы он ни был): программа сама
следит за адресом роутера и обновляет имя. Если имя вдруг не открывается, пользуйтесь запасным адресом с цифрами, его напишет
установщик (вида `http://192.168.X.1:8765`). Появится форма **«Вход в Дневник.ру»**.

> Почему не «адрес:слово»: после двоеточия в адресе может стоять только число (номер порта), это правило интернета.
> Поэтому слово стоит вместо цифр адреса: `dnevnik.lan`, а номер порта скрыт и вводить его не нужно.

**3. Войдите в Дневник.ру.** Здесь есть тонкость, если ребёнок входит на сайт **через Госуслуги**:

- У ученика в Дневник.ру есть **собственный логин и пароль**, отдельные от Госуслуг (зайдите на dnevnik.ru как обычно →
  профиль ученика → «Настройки» → «Логин и пароль»: там виден логин, а пароль можно задать кнопкой «Изменить»).
  Введите этот логин и пароль на нашей странице. **Пароль от Госуслуг сюда вводить не нужно и нельзя.**
- Через минуту появятся домашка и оценки. Если сайт не принимает логин и пароль (так бывает, если в вашем регионе
  вход возможен только через Госуслуги), используйте запасной вариант ниже.

**Запасной вариант: вход через Госуслуги на компьютере.** Если пароль Дневник.ру в вашем регионе недоступен (вход только через
Госуслуги), войти нужно на компьютере: подробная инструкция для Windows, Mac и Linux ниже, раздел «Войти заново через компьютер».
Вход через Госуслуги **продлевается сам**, пока программа работает: сайт сдвигает срок действия при каждом обращении, поэтому повторно
входить придётся редко (проверено: срок 14 дней сдвигается при каждом обновлении). Точный предел неизвестен: у сайта есть ещё одна кука
на 30 дней, так что первый ориентир проверки около месяца после входа. Если роутер был выключен больше двух недель, вход придётся повторить.

**Всё.** Дальше программа сама обновляется раз в 20 минут (с 6:00 до 23:00) и входит заново, когда нужно (если сохранён пароль).
Токены не нужны.

**Выйти из аккаунта** (кнопка ⚙ → «Выйти из аккаунта»): нужны **два подтверждения** подряд, и второе проверяет сам роутер (на втором окне кнопка
включается через пару секунд, а без первого шага роутер выход не примет). При выходе прежний профиль сразу исчезает со страницы и из
памяти устройства, а вход и данные **не стираются, а прячутся на сутки**: на экране входа есть кнопка «Вернуть прежний вход».
Через сутки копия удаляется. Важно: если вы входите только через Госуслуги, войти заново можно по паролю Дневник.ру (см. выше) или
запасным способом на компьютере.

**Значок на главном экране:** iPhone — Safari → «Поделиться» → «На экран “Домой”». Android — Яндекс Браузер или Chrome →
меню ⋮ → «Добавить на главный экран».

## Войти заново через компьютер (Windows, Mac, Linux)

Это нужно при первой настройке, если вход у вас только через Госуслуги, и потом очень редко: когда на странице дневника написано
«Нужно войти в Дневник.ру заново» (роутер был выключен больше двух недель или у сайта вышел срок). Подойдёт **любой компьютер**, свой или
чужой, если он в той же домашней Wi-Fi или подключён к роутеру проводом. Всё делается одной командой, примерно 10 минут в первый раз
(потом пара минут).

**Что понадобится**
- Компьютер с Windows 10 или 11, Mac или Linux, интернет.
- **Пароль от роутера**, тот же, что вы вводите на странице настроек роутера (LuCI). Это пароль пользователя `root`.
- Логин и пароль ученика от Госуслуг. Если у аккаунта включено подтверждение входа, Госуслуги пришлют код: тогда держите телефон под рукой.
- Адрес роутера. Если вы его не меняли, это `192.168.10.1`.

**Шаг 1. Скачайте программу.** Откройте страницу программы на GitHub (github.com/Rombaldo/dnevnik-OpenWRT), нажмите зелёную кнопку
**Code → Download ZIP**, распакуйте архив (на Windows: правая кнопка → «Извлечь всё»). Получится папка `dnevnik-OpenWRT-main`.

**Шаг 2. Поставьте Python**, если его нет (нужна версия 3.9 или новее). Проверить: в терминале `python3 --version` (Windows: `py -3 --version`).
- **Windows:** скачайте установщик на python.org/downloads, при установке **обязательно поставьте галочку «Add python.exe to PATH»**.
- **Mac:** обычно уже есть. Если Mac предложит «установить средства командной строки», согласитесь.
- **Linux:** `sudo apt install python3 python3-venv` (в других системах пакеты называются похоже).

**Шаг 3. Запустите вход.**
- **Windows:** откройте папку `dnevnik-OpenWRT-main` и дважды щёлкните по файлу **`login-windows.bat`**. Если Windows предупредит, что файл
  неизвестного издателя, выберите «Подробнее → Выполнить в любом случае». Или откройте PowerShell в этой папке (в проводнике: клик в адресную
  строку, написать `powershell`, Enter) и выполните: `py -3 tools\login_computer.py`
- **Mac:** откройте «Терминал» и выполните (папку при необходимости поправьте): `cd ~/Downloads/dnevnik-OpenWRT-main` и затем
  `python3 tools/login_computer.py`
- **Linux:** в терминале `cd` в папку программы и `python3 tools/login_computer.py`. Если браузер не запустится из-за недостающих
  библиотек, один раз выполните `sudo .venv/bin/python -m playwright install-deps chromium`.

Если роутер у вас не по адресу `192.168.10.1`, добавьте в конец команды `--router АДРЕС` (например `--router 192.168.1.1`).

**Шаг 4. Первый запуск готовит окружение.** Скрипт сам скачает нужное (около 200 МБ, 2–5 минут, один раз). Ничего вводить не нужно, дождитесь
надписи «Войдите через Госуслуги в открывшемся окне».

**Шаг 5. Войдите через Госуслуги.** Откроется окно браузера со страницей входа Дневник.ру. Нажмите **«Войти через Госуслуги»** и войдите
как обычно (логин и пароль; код из СМС нужен, только если Госуслуги его запросят). **Пароль от Госуслуг вводится только в этом окне, у Госуслуг; программа его не видит и не
сохраняет.** Когда вы попадёте в дневник, окно закроется само (на вход есть 10 минут).

**Шаг 6. Введите пароль роутера.** В терминале появится «Передаю вход на роутер». Если спросит `Are you sure you want to continue connecting`,
напишите `yes` и Enter. Потом введите пароль роутера (при вводе ничего не отображается, это нормально) и Enter.

**Шаг 7. Готово.** Через минуту-две скрипт напишет «Готово: дневник загрузился». Откройте `http://dnevnik.lan` на телефоне.

**Если компьютер чужой.** Добавьте к команде ключ `--forget`, тогда после передачи вход сотрётся с этого компьютера
(например `python3 tools/login_computer.py --forget`). Потом удалите папку программы и скачанный браузер: `.venv` внутри неё.

**Что именно передаётся на роутер.** Только вход в Дневник.ру (cookie сайта dnevnik.ru) и номера ученика и школы. Cookie Госуслуг и
Яндекса отбрасываются ещё на компьютере. Передача идёт по SSH, это зашифрованный канал, а роутер проверяет присланное и записывает файлы
с правами только для root.

**Если что-то не получилось**
- **«Не найдена программа ssh»** (Windows): Параметры → Приложения → Дополнительные компоненты → Добавить компонент → «Клиент OpenSSH».
  Потом запустите снова с ключом `--no-browser`: заново входить через Госуслуги не нужно, вход уже сохранён на компьютере.
- **«Permission denied»**: неверный пароль роутера. Запустите команду снова с ключом `--no-browser` и введите пароль ещё раз.
- **«Connection timed out» или «No route to host»**: компьютер не в домашней сети или неверный адрес роутера (`--router`).
- **Окно браузера не открылось или закрылось**: запустите команду заново; Госуслуги иногда просят повторить вход.
- **Вход через ключ SSH вместо пароля**: добавьте `--identity путь\к\ключу`.
- Не уверены, что получилось: откройте `http://dnevnik.lan`, там должны появиться домашка и оценки. Журнал на роутере:
  `tail /tmp/dnevnik-sync.log`.

На Mac с настроенным ключом доступа удобнее прежняя команда `./dev.sh login`: она не спрашивает пароль роутера.

## Можно ли поставить другим родителям
Да, программа открытая и бесплатная (лицензия MIT). Но стоит знать:
- **Каждая семья ставит у себя** и вводит логин и пароль **своего** ребёнка. Ничьи данные ни к вам, ни к автору не попадают.
- **Нужен роутер с OpenWrt** (как выше) **или любой компьютер**, который можно держать включённым: тогда роутер не нужен.
  На компьютере: установите Python 3.9 или новее, скачайте программу (кнопка «Code → Download ZIP» на странице репозитория на GitHub),
  откройте терминал в папке и выполните `python3 server.py`. Страница откроется на `http://localhost:8765`, а с телефона по адресу
  компьютера, который программа напишет при запуске. Логин и пароль вводятся на странице, как и для роутера.
- **У ученика должен быть логин и пароль от Дневник.ру** (профиль → «Настройки» → «Логин и пароль»). Если ребёнок входит только через
  Госуслуги, пароль можно задать там же кнопкой «Изменить».
- Программа проверена на **школьной учётной записи ученика**. Родительская учётная запись (несколько детей) не проверялась.
- Если школа или сайт что-то поменяют, программа может временно перестать работать до обновления.

## Если что-то пошло не так
- **Страница не открывается.** Телефон должен быть в домашней Wi-Fi (не на мобильном интернете). Если не открывается имя `dnevnik.lan`,
  выключите на телефоне «Частный DNS» / «Защищённый DNS» (он обходит DNS роутера) или откройте запасной адрес с цифрами.
- **Страница просит снова ввести логин и пароль.** Значит, пароль на сайте сменили или сайт потребовал капчу.
  Введите актуальный пароль (если сайт просит капчу: один раз войдите на dnevnik.ru в браузере, введите капчу и повторите).
- **Страница просит «Пароль семьи».** Это включённый вами пароль (⚙ → «Пароль для семьи»). Забыли: задайте новый в LuCI («Службы → Дневник → Пароль семьи») или по SSH, см. раздел про пароль.
- **Обновить программу до новой версии:** та же команда, что для установки. Ваш вход и данные при этом не трогаются.
- **Убрать программу:** `sh /root/dnevnik/router/uninstall.sh` (с `--keep` данные остаются). Страница в LuCI убирается вместе с ней.
- **Журнал обновлений:** `tail /tmp/dnevnik-sync.log` на роутере.
- После форматирования роутера всё стирается: повторите шаги 1–3.

## Пароль для семьи (по желанию, обязательно, если страница открыта из интернета)

Один общий пароль на всю семью. Задаётся на самой странице: **⚙ → «Пароль для семьи» → «Задать пароль»** (любой, даже из одного символа; но короткий легко подобрать, особенно если страница открыта из интернета, лучше фраза из нескольких слов).
С этого момента без пароля не отдаётся ничего: ни оценки и домашка, ни кнопки «Обновить» и «Выйти из аккаунта», ни форма входа в Дневник.ру.
Каждое устройство вводит пароль один раз и запоминает его на полгода.

Пароль можно задать, сменить и отключить и **в веб-интерфейсе роутера**: «Службы → Дневник → Пароль семьи» (нужна установка с `--luci`).
Там старый пароль знать не нужно: вход в LuCI защищён паролем администратора роутера, поэтому только хозяин роутера может задать новый.
Так же сбрасывается **забытый пароль**: задайте новый в LuCI, и все устройства войдут заново.

**Подсказка к паролю** (по желанию) показывается на экране входа. Её видит каждый, кто откроет страницу, поэтому программа не принимает
подсказку, в которой есть сам пароль, а в полях ввода это написано. Хорошая подсказка: «имя кота и год», плохая: «пароль от почты».

- **Где хранится:** только на роутере, в виде хеша (PBKDF2 с солью), файл `/root/dnevnik/data/auth.json` с правами 600. Сам пароль нигде не лежит.
- **Смена и отключение** требуют и вход на устройстве, и текущий пароль. После смены все остальные устройства попросят новый пароль.
- **Перебор тормозится:** после 5 неверных попыток подряд ждать 30 секунд, потом 1, 2, 4 минуты и так до 15 минут.
- **Данные не лежат в открытой папке веб-сервера:** их отдаёт только `cgi-bin/data` после проверки пароля, прямой ссылкой на файл их не получить.
- **Забыли пароль.** Два способа: в LuCI («Службы → Дневник → Пароль семьи», задать новый) или на роутере по SSH:
  `python3 /root/dnevnik/router/password.py set 'новый пароль' 'подсказка'` (подсказку можно не писать; `off` отключает пароль, `status` показывает состояние).
  Со страницы дневника пароль без текущего пароля не сбросить, это сделано намеренно: иначе его сбросил бы кто угодно.
- Пока пароль не задан, страницу видит любой, кто до неё достучался. Не открывайте страницу в интернет, не задав пароль.

## Кто подключён и кто заходил («Устройства и входы» в LuCI)

В LuCI («Службы → Дневник → Устройства и входы») видно:
- **Подключены к уведомлениям:** какое устройство (имя, которое вы дали при включении, и тип: «iPhone · Safari», «Android (SM-X710) · Chrome»), через какую службу (Apple, Google, Mozilla), когда подключено, есть ли сбои. Кнопка **«Отключить»** убирает устройство из уведомлений (включить снова можно на самом телефоне).
- **Кто открывал дневник** (с последней перезагрузки роутера): тип устройства, откуда (из дома, из интернета, через Tailscale) и когда последний раз.
- **Журнал входов по паролю семьи:** успешные входы и **неверные попытки** (подряд идущие с одного устройства сливаются в одну строку «×N»). За сутки неверных попыток больше 10: «Проверить всё» предупредит, что кто-то подбирает пароль.

Устройства различаются по типу и браузеру, а не по имени человека: при включении уведомлений (⚙ → «Уведомления») можно вписать название устройства, например «Планшет Ани». **Адреса не записываются**: из интернета роутер видит запрос как свой собственный (так работает Funnel), из дома видно лишь «из дома».
Журнал хранится на роутере (`data/logins.json`, до 50 записей, права 600), список «кто открывал» только в оперативной памяти. Кнопка «Очистить журнал» стирает оба. Отдельная сессия отзывается пока только сменой пароля (все устройства войдут заново).

## Уведомления о новых оценках, домашке и пропусках

Дневник может присылать **уведомления на телефон**, даже когда страница закрыта: о новой оценке, новой домашке, отмене и переносе уроков, пропусках и опозданиях. Включается **на каждом устройстве отдельно**
(у родителя можно всё, у ребёнка только домашку), работает на **Android (Chrome)** и **iPhone (Safari, iOS 16.4 и новее)** без установки приложений.

**Как включить**
1. Один раз на роутере (нужно около 4 МБ места): `sh /root/dnevnik/router/push.sh` (или при установке ключ `--push`). Это ставит один пакет, `python3-cryptography`, для шифрования уведомлений.
2. На телефоне откройте дневник **по адресу из интернета** (он начинается с `https://`; по домашнему `dnevnik.lan` уведомления не работают, это правило браузеров). На iPhone страница должна быть **добавлена на экран «Домой»** и открыта оттуда.
3. ⚙ → **«Уведомления»** → «Включить уведомления на этом устройстве» → разрешите уведомления → **«Проверить уведомление»**: оно придёт в течение минуты.
4. Там же выберите, о чём сообщать, и задайте **тихие часы** (в это время уведомления не приходят, утром придёт сводка). Раздел «Что нового» показывает последние события, даже если уведомления выключены.

**Приватность.** Текст уведомления **шифруется для самого телефона** (стандарт Web Push, RFC 8291) и пересылается через серверы Google (Android) или Apple (iPhone) уже зашифрованным: прочитать его они не могут, видят только, что устройству что-то пришло и когда.
Ключ отправителя и список устройств хранятся только на роутере (`data/push.json`, права 600). Роутер принимает подписки только от известных служб уведомлений (Google, Apple, Mozilla, Microsoft). Включать и менять настройки можно только с паролем семьи.

**Как это работает.** После каждого обновления данных (раз в 20 минут, с 6 до 23) роутер сравнивает новое со старым и находит события. Поэтому уведомление приходит с задержкой **до 20 минут**. Первое обновление после установки ничего не присылает
(иначе пришли бы все прежние оценки разом). Если событий много, придёт одна сводка. Не больше 20 устройств.

**Если не работает**

| Что видите | Что делать |
|---|---|
| «Не установлен модуль уведомлений» | на роутере: `sh /root/dnevnik/router/push.sh` |
| «Уведомления работают при входе по адресу из интернета» | откройте дневник по адресу `https://…` (из «Приглашения для семьи» в LuCI) |
| iPhone: «Добавьте на экран Домой» | Safari → «Поделиться» → «На экран Домой», открыть значок, включить там; нужна iOS 16.4+ |
| «Проверить уведомление» не приходит | проверьте разрешение для сайта в настройках телефона; `python3 /root/dnevnik/router/doctor.py` покажет состояние («Уведомления»); выключите и включите на этом устройстве заново |
| Нет места для модуля | освободите ~4 МБ (удалите ненужные пакеты); дневник и без уведомлений работает |

## Доступ из интернета (Tailscale Funnel)

Чтобы дневник открывался не только дома, на роутер ставится бесплатный **Tailscale**, а дневник «выводится» через его функцию **Funnel**. Результат: постоянный адрес `https://dnevnik.<ваша-сеть>.ts.net`, который работает в любой сети, на любом телефоне и компьютере, **без установки приложений**. Этот адрес защищён паролем семьи.

**Как включить:** программа установки с компьютера (способ А) или на роутере `sh /root/dnevnik/router/remote.sh` (повторные запуски безопасны: сделанное пропускается). Скрипт:

1. проверяет, что дневник установлен, что хватает места (около 15 МБ) и что **задан пароль семьи** (без него в интернет не выставляет);
2. ставит пакет `tailscale` и запускает службу;
3. показывает ссылку для входа в **ваш** аккаунт Tailscale: войдите и **обязательно нажмите «Connect device»** (одного входа мало);
4. при первом включении просит один раз нажать **«Enable Funnel»** (включаются Funnel и HTTPS-сертификаты; имя `dnevnik.<сеть>.ts.net` при этом навсегда попадает в публичный журнал сертификатов, больше ничего о вас там не будет);
5. включает Funnel на дневник и печатает адрес.

**Проверьте:** выключите на телефоне Wi-Fi, откройте адрес через мобильный интернет, введите пароль семьи, добавьте страницу на экран «Домой». Готовый текст-приглашение для семьи (адрес и инструкция) есть в LuCI: «Службы → Дневник → Приглашение для семьи». Адрес даёте только семье: у каждой семьи свой аккаунт Tailscale и свой адрес, чужим аккаунтом пользоваться нельзя.

**Выключить:** `sh /root/dnevnik/router/remote.sh funnel off` (дневник уходит из интернета, дома работает).

### Прокси для Tailscale: что реально помогло и когда это нужно

У некоторых провайдеров Tailscale на роутере доходит до входа в аккаунт, но дальше «зависает»: в статусе остаётся `NeedsLogin`, хотя вы нажали «Connect device», а в журнале видно, что регистрация прошла. Так было и у нас. **Помогло одно изменение**: подать трафик Tailscale в локальный прокси на роутере (у нас это SSClash/Clash, порт 7890). Для этого в файл запуска службы `/etc/init.d/tailscale` добавляется строка с переменными окружения:

```
HTTPS_PROXY=http://127.0.0.1:7890  HTTP_PROXY=http://127.0.0.1:7890  NO_PROXY=127.0.0.1,localhost,192.168.0.0/16
```

После этого нужно снова войти (ещё раз «Connect device»), и Tailscale заработал.

- **Делается само.** `remote.sh`: если после входа Tailscale не подключился, а на роутере слушает прокси на `127.0.0.1:7890`, скрипт сам включает эту строку и повторяет вход. Вручную: `sh /root/dnevnik/router/remote.sh proxy on` (можно указать другой адрес: `proxy on 127.0.0.1:7891`), отключить: `sh /root/dnevnik/router/remote.sh proxy off`.
- **Если прокси нет** (на роутере нет Clash/SSClash), эту строку не нужно: во многих сетях Tailscale работает напрямую.
- **Цена.** Пока строка включена, Tailscale зависит от прокси: если Clash/SSClash остановить, связь Tailscale (и адрес из интернета) пропадёт. Помощник «Проверить всё» это показывает: «Прокси для Tailscale: включён, он отвечает» или «ничего не слушает».
- **Что именно меняется.** Только блок между строками `# >>> dnevnik-proxy` и `# <<< dnevnik-proxy` в `/etc/init.d/tailscale`; исходный файл сохраняется как `/etc/init.d/tailscale.bak-dnevnik`. Обновление пакета `tailscale` может затереть правку: тогда выполните `remote.sh proxy on` ещё раз.
- **Как узнать, нужен ли прокси.** После `remote.sh` без прокси проверьте `tailscale status`: если показано `Running`, прокси не нужен. Если после нажатия «Connect device» остаётся «Logged out» / `NeedsLogin`, а прокси на роутере есть, он нужен.

## Что нужно знать о безопасности
- **Уведомления** шифруются для телефона (Web Push); Google и Apple видят только факт доставки. Подписки принимаются только от известных служб, настройки и подписка защищены паролем семьи.
- **Доступ из интернета** (если включили): страница закрыта паролем семьи, данные отдаются только после проверки пароля, перебор тормозится. Tailscale видит, что на ваш адрес
  приходят зашифрованные соединения, но не видит их содержимого. Без пароля программа в интернет ничего не выставляет, а «Проверить всё» отмечает такой случай красным.
- Логин и пароль хранятся **только на вашем роутере**, в закрытом файле `/root/dnevnik/data/credentials.json` (читает только root).
  В пароле нет секрета от других сервисов: это пароль только от Дневник.ру. Госуслуги программе не нужны.
- Программа только **читает** дневник: ничего не отмечает и ничего не отправляет.
- По умолчанию страница доступна всем устройствам вашей домашней Wi-Fi без пароля, а из интернета её не видно. Если хотите
  открывать дневник и вне дома (или просто закрыть его от гостей), включите **пароль для семьи** (раздел ниже).
- Файлы-вложения не хранятся: на странице ссылка, файл открывается прямо с сервера Дневник.ру.
- Что делает программа на роутере: ставит несколько пакетов Python, кладёт файлы в `/root/dnevnik`, добавляет службу `dnevnik`
  (веб-сервер на порту 8765; при установке с `--luci` ещё четыре маленьких файла страницы «Службы → Дневник»), одну строку в расписание cron и **запись в DNS роутера** (имя `dnevnik.lan`; на стартовой странице роутера
  адрес `http://dnevnik.lan` без порта перенаправляет на дневник, а адрес роутера по цифрам открывает его, как раньше). Всё это убирает
  `uninstall.sh`. Настройки интернета, Wi-Fi и прокси она не меняет.

## Для разработчика

Все команды через `./dev.sh`:

| Команда | Что делает |
|---|---|
| `./dev.sh setup` | создаёт окружение и ставит зависимости (один раз) |
| `./dev.sh demo` | страница на **выдуманных данных**: http://localhost:8766 |
| `./dev.sh test` | все тесты (в том числе страница в настоящем браузере) |
| `./dev.sh secrets` | проверка файлов и всей истории git на секреты |
| `./dev.sh deploy` | выложить программу с Mac на роутер по SSH-ключу `data/router_key` |
| `./dev.sh update` | обновить роутер из GitHub (через токен, если репозиторий приватный) |
| `./dev.sh router` | журнал и файлы данных на роутере |
| `./dev.sh run` | запустить на этом компьютере с настоящими данными (то же, что `python3 server.py`) |
| `python3 tools/setup_computer.py` | установка на роутер с компьютера одним запуском (Windows: `setup-windows.bat`, Mac: `Установить-на-роутер.command`) |
| `./dev.sh login` | запасной вход через Госуслуги в окне браузера на Mac (если на сайте нет логина и пароля) |
| `python3 tools/login_computer.py` | то же на любом компьютере (Windows: `login-windows.bat`), с передачей на роутер по SSH-паролю |

Устройство: `core.py` — вход, разбор данных и обновление (только стандартная библиотека, работает на роутере);
`sync.py` — одно обновление (запускается cron); `router/` — установщик, служба, скрипты (`setup.cgi` принимает логин и пароль со страницы, `logout.cgi` делает выход в два шага и возвращает вход, `luci.sh` ставит и убирает страницу LuCI);
`luci/` — страница «Службы → Дневник» (`rpcd/luci.dnevnik` серверная часть, `htdocs/` сама страница, `menu.d/` и `acl.d/` меню и права);
`web/` — страница; `fetcher.py` и `server.py` — вход через браузер и сервер для Mac; `dev/sample.py` — выдуманные данные для тестов.

Версия в `VERSION`, список изменений в `CHANGELOG.md`. Выпуск: поднять `VERSION`, дописать `CHANGELOG.md`, `./dev.sh test`,
коммит, тег `vX.Y.Z`, `git push --tags`.

**Секреты не должны попадать в git:** `data/` (вход, ключ роутера, история), `config.json`, токены. Это закрыто `.gitignore`,
хуком перед коммитом и `./dev.sh secrets` (проверяет всю историю). Для приватного репозитория установщик умеет брать токен
GitHub только на чтение из `/root/.dnevnik-token` (`./dev.sh token` кладёт его на роутер).

Как устроен вход: логин и пароль проверяются формой входа Дневник.ру (`login_with_password`), сохраняются и используются
только для входа на `dnevnik.ru`. Cookie отправляются только на `dnevnik.ru` по HTTPS, проверка сертификатов всегда включена.
После неудачного входа повтор не раньше чем через 6 часов (чтобы не заблокировали учётную запись), пока не введены новые данные.
Тексты с сайта на странице экранируются (есть тест).
