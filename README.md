# Мой дневник (домашняя страница для Дневник.ру)

Показывает домашку, оценки и расписание из веб-версии Дневник.ру в простом виде.
Работает по домашнему Wi-Fi. Mac должен быть включён.

## Каждый день
- Двойной щелчок по **Запустить.command** (окно оставьте открытым, можно свернуть).
- На телефоне и планшете открыть `http://<адрес Mac>:8765`. Адрес печатается при запуске.
  Это что-то вроде `http://192.168.x.x:8765` (если роутер выдаст Mac другой адрес, он изменится, тогда `./dev.sh qr` делает новый QR-код).
- Данные обновляются раз в 20 минут, ночью (23:00-6:00) не обновляются. Кнопка «Обновить» делает это сразу.

## Если страница пишет «Нужно войти заново»
Вход через Госуслуги со временем истекает. Двойной щелчок по **Войти.command**,
в открывшемся окне войти через Госуслуги. Окно закроется само.

## Без интернета
По адресу `/offline.html` скачивается копия страницы с данными внутри. Её можно открыть на устройстве без сети.

## Заметки
- Программа только читает дневник, ничего не отмечает и не отправляет.
- Галочки «сделано» хранятся только в браузере устройства.
- Папка `data/` содержит сохранённый вход (`session.json`). Никому не отправлять и не выкладывать.
- Страница доступна всем в вашей домашней сети. Из интернета она не видна.

## Для разработки
Все команды через `./dev.sh`:

| Команда | Что делает |
|---|---|
| `./dev.sh setup` | создаёт окружение и ставит зависимости (один раз) |
| `./dev.sh demo` | запускает страницу на **выдуманных данных**: http://localhost:8766, входить в Дневник.ру не нужно |
| `./dev.sh test` | запускает все тесты (в том числе проверку страницы в настоящем браузере) |
| `./dev.sh run` | запускает с настоящими данными (как «Запустить.command») |
| `./dev.sh qr` | делает QR-код с адресом страницы для телефона |
| `./dev.sh login` / `sync` | вход через Госуслуги / одно обновление данных |

### Версии
- Номер версии лежит в файле `VERSION`, список изменений в `CHANGELOG.md`. Номер виден внизу страницы.
- Перед коммитом: `./dev.sh test`. Для релиза поднять `VERSION`, дописать `CHANGELOG.md`, коммит и тег `git tag vX.Y.Z`.
- Тест проверяет, что версия из `VERSION` есть в `CHANGELOG.md`.

### Личные данные в git не попадают
`data/` (вход, оценки, домашка), `config.json` (имя), `.venv/` и QR-код с адресом домашней сети добавлены в `.gitignore`.
Сверх этого хук `.githooks/pre-commit` блокирует коммит, если туда всё же попали такие файлы или cookie входа.
Хук включается командой `git config core.hooksPath .githooks` (в этой копии уже включён).
Образец настроек: `config.example.json`. В демо-режиме и тестах используются только выдуманные данные из `dev/sample.py`.
