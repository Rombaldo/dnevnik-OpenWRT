# История версий

Формат: номер версии, дата, что изменилось. Версию меняем в файле `VERSION`.

## 0.8.0 — 2026-11-11
- **Адрес словом:** `http://dnevnik.lan` вместо цифр и порта. Не зависит от адреса роутера: имя привязано к текущему адресу и обновляется
  само при старте службы и при смене адреса (`router/setname.sh`, запись в DNS роутера + hotplug). Адрес `http://dnevnik.lan` без порта
  ведёт на дневник через стартовую страницу роутера, адрес по цифрам открывает роутер, как раньше. `uninstall.sh` всё возвращает.
- **Смена логина и пароля — двойное подтверждение:** два окна подряд («Сменить?» и «Вы точно хотите выйти из этого аккаунта?»),
  на втором кнопка «Да» включается через 2 секунды, безопасная кнопка выбрана по умолчанию, окна закрываются Escape и нажатием мимо.
- Форма входа и сообщения честно объясняют: нужны логин и пароль самого Дневник.ру (не Госуслуг); как задать пароль в профиле.
- Исправлен цвет текста на синих кнопках (не была определена переменная цвета).
- Проверено: вход через Госуслуги сам продлевается при каждом обращении (срок 14 дней сдвигается), поэтому он держится, пока
  программа работает. В инструкции описан запасной вход через Госуслуги на компьютере.
- 93 теста.

## 0.7.0 — 2026-11-11
- В шапке страницы имя ученика и школа, как на сайте («Аня (МБОУ "Школа № 1")»); фамилия не сохраняется. Если имя не задано в
  настройках, приветствие берёт имя с сайта.
- **Оценки по годам и итоговые:** раздел «По годам и итоги». Все учебные годы ученика (в том числе прошлые классы), для каждого
  оценки по триместрам со средним баллом и итоги (за каждый триместр и за год) в таблице, как на сайте в «Успеваемости».
  Прошлые годы запрашиваются раз в 30 дней, идущий год раз в 3 часа; сбой этого раздела не мешает домашке и расписанию.
- Лицензия MIT, оговорки («неофициальная программа»), раздел «Можно ли поставить другим родителям», запуск на обычном компьютере
  без роутера (проверено из чистой копии на системном Python 3.9).
- 89 тестов.

## 0.6.0 — 2026-11-11
Программа стала самодостаточной: ни Mac, ни Госуслуги, ни токены для работы больше не нужны.
- **Вход по логину и паролю ученика** (у Дневник.ру он есть в профиле: «Настройки» → «Логин и пароль»). Вводится один раз
  в форме на самой странице; роутер проверяет его на сайте и сохраняет в закрытом файле. Дальше сам входит заново, когда вход истекает.
- Поиск номеров ученика и школы теперь тоже без браузера.
- Защита аккаунта: после неудачного входа повтор не раньше чем через 6 часов; форма на роутере принимает не чаще одной попытки в 10 секунд;
  неудачная попытка не затирает рабочий вход; нет интернета не путается с неверным паролем; капча показывается понятным текстом.
- Установщик больше не требует токена (для публичного репозитория): одна команда `wget -qO- …/install.sh | sh`.
- Страница: форма «Вход в Дневник.ру» при первом запуске, кнопка «Сменить логин и пароль», предупреждение при проблеме со входом.
- Инструкция в `README.md` написана для обычного человека. Тесты: вход, капча, неверный пароль, повторный вход, форма (71 тест).

## 0.5.4 — 2026-11-11
- **Исправлено:** после установки из GitHub страница на роутере отвечала «403 Forbidden». Строгие права на временный файл с токеном
  (`umask 077`) распространялись на весь установщик, и файлы страницы создавались закрытыми от веб-сервера. Теперь строгие права
  только у файла с токеном, файлы страницы всегда читаемы (в установщике, в службе и в самом коде), вход и история остаются 600.
- Установщик после установки проверяет, что страница отвечает, и иначе сообщает об ошибке. Тест на права при строгом umask.

## 0.5.3 — 2026-11-11

  Проверено полностью: роутер сам скачивает версию из приватного репозитория GitHub по токену только на чтение и устанавливает.

## 0.5.0 — 2026-11-11
Проверка безопасности входа и установка из GitHub.
- **Исправлено:** в файле входа лежали cookie не только Дневника.ру, но и Госуслуг и Яндекса (37 штук с 9 сайтов). Теперь
  сохраняются и используются только cookie Дневника.ру (17 штук); старый файл на Mac и на роутере очищен.
- Папка `data/` закрыта правами 700, файлы входа 600. Окно входа в Госуслуги запускается в песочнице браузера.
- Сканер секретов `scripts/check-secrets.sh` (файлы, ключи, токены GitHub, cookie входа, номера ученика) в хуке перед коммитом
  и командой `./dev.sh secrets` для всей истории git. Проверен на выдуманных «секретах».
- Номер урока на странице тоже экранируется. Тест: теги и скрипты в текстах от сайта не выполняются.
- Установка на роутер из приватного репозитория GitHub одной командой (`router/install.sh`), обновление `./dev.sh update`,
  удаление `router/uninstall.sh`. Токен GitHub только на чтение лежит на роутере в файле с правами 600.
- Тесты безопасности: куда отправляются cookie, проверка сертификатов, сканер секретов (41 тест).

## 0.4.0 — 2026-11-11
Страница переезжает на роутер, чтобы работать без включённого Mac.
- Обновление данных теперь идёт обычными запросами без браузера (`core.py`, `sync.py`): работает на роутере и на Mac.
  Браузер нужен только для входа через Госуслуги (`fetcher.py login`). Результат совпал со старым способом: 57 дней, 0 отличий.
- Вложения к домашке больше не скачиваются и нигде не хранятся: на странице ссылка, файл открывается прямо с сервера Дневник.ру.
  Ссылки с чужих серверов отбрасываются.
- Установка на роутер с OpenWrt (`router/`): отдельный веб-сервер на порту 8765, обновление раз в 20 минут с 6:00 до 23:00,
  кнопка «Обновить», автозапуск после перезагрузки. Данные для страницы лежат в оперативной памяти роутера, на флеш-память
  пишется только то, что изменилось, вход не чаще раза в 6 часов.
- `Войти.command` после входа через Госуслуги сам передаёт вход на роутер.
- Тесты: проверка обновления на поддельном сайте (вход, истёкший вход, смена cookie, ошибка сайта, восстановление после перезагрузки).

## 0.2.0 — 2026-11-11
- «Домашка» переделана по образцу приложения Дневник.ру: лента карточек по дням (дата, «ДЗ на день 0/4», полоса прогресса,

- Сервер отдаёт файлы только известных типов и только те, что сам скачал. Тесты на это добавлены.

## 0.1.0 — 2026-11-11
Первая рабочая версия.
- Сборщик данных `fetcher.py`: вход через Госуслуги вручную (один раз), дальше чтение дневника под сохранённым входом.
- Сервер `server.py`: обновление раз в 20 минут (ночью не обновляет), кнопка «Обновить», копия страницы для офлайна.
- Страница: «Домашка» (с отметкой «сделано»), «Оценки», «Расписание»; крупный шрифт, тёмная тема, две колонки на планшете.
- «Оценки»: средний балл, последние оценки, по предметам, блок «Как у тебя дела», направление рейтинга (места в рейтинге
  Дневник.ру платные и не показываются).
- Среда разработки: git, демо-режим с выдуманными данными, тесты, защита от случайной публикации личных данных.
